# Fetch Web Page Node

The **Fetch Web Page Node** fetches and renders the HTML content of a web page from any HTTP or HTTPS URL using a GET request. It is designed for previewing and extracting content from web pages, not for general API integration.

## Credentials in the URL

A key saved in [Settings → Credentials](/docs/getting-started/configuration#credentials) can go into the URL as `{{name}}`, for example `https://example.com/report?token={{myToken}}`.

- The value is filled in only to fetch the page, exactly as it is saved. A whole URL saved as a credential works too: `{{myPrivatePageUrl}}`.
- The node and the workflow file keep `{{myToken}}`. Errors show the placeholder, not the value.
- If the name isn't saved, or the vault is locked, the node stops with an error that says which.

## Example Usage

For example usage, see the [Weather Dashboard workflow](/docs/workflows/data/weather-dashboard) or [Google Drive Listing workflow](/docs/workflows/data/gdrive-listing), which demonstrate fetching and displaying web page content.

## Common Use Cases

1. **Web Page Preview**: Render and inspect the HTML content of a web page.
2. **Content Extraction**: Use downstream nodes to extract or process information from the rendered HTML.
3. **Workflow Debugging**: Check what a web page returns before further processing.

## Best Practices

- **Use valid URLs**: Ensure the URL is correct and accessible.
- **Handle errors**: Downstream nodes should handle possible fetch errors or missing data.
- **Avoid dynamic/authenticated pages**: The node does not support login or session management.

## Troubleshooting

### Common Issues

- **Invalid URL**: Check for typos or missing protocol (`http://` or `https://`).
- **Network errors**: Verify your internet connection and endpoint availability.
- **Unexpected content**: Some web pages may block automated requests or require authentication.

### Performance Tips

- Avoid fetching very large or complex web pages unless necessary.
- Use downstream nodes to process or extract only the needed information.
